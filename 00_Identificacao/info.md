## Resumo curto
O EloTask é uma plataforma web de colaboração e gestão de projetos que integra, num único ambiente, equipas, projetos, tarefas, mensagens, reuniões, calendário e gestão de turnos. Responde à dispersão de informação causada pela utilização de várias aplicações no trabalho em equipa e vai focar-se nos estudantes. O frontend é feito em HTML, CSS e JavaScript, o backend em Node.js com API REST e Socket.IO, e os dados ficam em MySQL. O sistema é distribuído: cada camada tem uma réplica no computador e outra em Docker, com balanceadores nginx e replicação da base de dados nos dois sentidos. Um serviço de Inteligência Artificial em Python resolve Problemas de Satisfação de Restrições (CSP) para gerar escalas de turnos e sugerir horários de reunião. A segurança assenta em JWT, palavras-passe com bcrypt e permissões verificadas no servidor.
